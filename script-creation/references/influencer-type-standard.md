# 度小满-达人类型基础标准（终版）

> 来源：飞书文档 https://kwza968lz1u.feishu.cn/docx/QDPOdmP6XoNiqpxmbl6cwNianCg
> 本文件是风格匹配步骤的**唯一类型判定标准**。判定达人属于哪个类型时，必须严格依据下表的「范围限定」，只能从下表的一级/二级类型中选取，不得自创类型。
> 特别规则：**军事点评账号归入「财经-泛财经」**（标准原文："军事点评我们也算入泛财经范畴"）。

## 类型体系（4 大类 8 二级）

| 一级达人类型 | 二级达人类型 | 范围限定 |
|---|---|---|
| 财经 | 泛财经 | 商业故事、个人财富、消费决策、搞钱思路、时政要闻、国内外热点等所有与"金钱""财富""商业活动"相关的点评，输出观点；军事点评也算入泛财经范畴；方向可以垂直但不涉及投资；方向也可以很广，任何时事要闻、小道新闻都要表达看法 |
| 财经 | 高价值 | 主要讲投资：贵金属、二级市场投资（股票、债券、基金等）、房产、进出口等涉及金融投资；日常都是垂直赛道（要么一直讲贵金属、要么一直讲二级市场）；政策分析、投资心得分享、市场洞察、投资产品推荐等 |
| 财经 | 小微企业主 | 自己必须是老板/合伙人，有自己的公司和业务；日常分析自己公司产业看法、吐槽或点评创业中遇到的事情；每天创业 vlog 等 |
| 生活 | 民生 | 选题全部来自"普通人正在经历、但自己说不清楚"的事，不追专业议程（不讲货币政策本身），只抓大众体感（钱变难赚了、婚不敢结了、学历不值钱了）；落点永远是"你个人怎么办"，不是"宏观怎么看"，宏观事件只当引子，三句话内必然折到个人决策；话题自带阶层站位（站普通打工人）；经济落点占比≥60%；人设=平视过来人，有可验证的平民经历叙事，无权威身份包装 |
| 生活 | 人文杂谈 | 选题源是"人活不明白"的困惑（人际体感：被拿捏、被套话、内耗、看不透人情世故），钱只是偶发话题无连续主线；落点是处世方法论或认知消遣（非金钱决策）；站位无阶层对抗性（说书人或阅历权威）；价值落点=处世方法论或见识趣味；关键检验：观众对该账号无"金钱托付感" |
| 三农 | 三农美食 | 围绕指定食材展开，一定有剧情演绎，核心是把食材有爽感地做饭；需要人物出镜说话，不能一直在厨房对着食材和锅拍摄；场景在农村（含少数民族场景如草原、窑洞）或城乡结合部，突出三农原生感；场景多元化（户外、院子、厨房） |
| 三农 | 三农建造 | 建造房子、家具、生活用具（泳池、猪圈等）手工内容，记录建造阶段或全程；需要人物出镜口播，不能只有旁白；每个视频都不能只提某个品牌家具或设备；场景可以在农村、野外，也可以在城市（如记录真实装修） |
| 剧情 | 常规剧情 | 剧情一般在1分钟以上；多人（非一人分饰多角）参与演出；多场景讲述剧情；剧情有人物关系、叙事结构（剧情梗概）、核心冲突；有完整的人物背景、故事起因、发展、高潮、结束/转折；叙事推进环环相扣 |
| 剧情 | 剧情搞笑 | 相比常规剧情，逻辑不严谨，时长可不到1分钟，主要体现无脑、耍丑、肢体动作搞笑；叙事推进可以不用环环相扣，会出现万万没想到的故事转折 |

## 账号举例（判定参考锚点）

- 财经-泛财经：商业小纸条、直言财经、达哥有点味（军事点评账号）
- 财经-高价值：小张小张吃饭用缸（吸钱哥）、财富觉醒社、许戈、大哲
- 财经-小微企业主：乡村大宁、豫游纪高公璞、包工头才哥
- 生活-民生：萌叔的小酒馆、朴素之道、刘雯
- 生活-人文杂谈：涵浪、万能春秋、赵大湿
- 三农-三农美食：董姐夫美食、周甄甄、江小子
- 三农-三农建造：建造哥户外生活、文子大大、手工耿
- 剧情-常规剧情：帅大斌的一天、三根葱、刘老二
- 剧情-剧情搞笑：太和小夫妻、猪肉佬、吴秀才、阿北先生

## 爆款热区（创意方向参考）

- 财经-泛财经：蹭热点（与每个人相关的钱话题，如数字人民币、国补、消费贷补贴）；讲借钱遇到的坑及避坑；直接硬广讲产品核心卖点（网贷和银行借钱门槛区别等）
- 财经-高价值：常规叙事"不要借钱投资"；揭秘自己的经济情况；揭秘投资行业从业者经济情况；蹭热点
- 财经-小微企业主：讲述发家史；讲述自己遇到的经济周转情况；讲鸡汤说过去和现在的不容易
- 生活-民生：待补充（标准终版未提供，后续按投放数据沉淀）
- 生活-人文杂谈：待补充（标准终版未提供，后续按投放数据沉淀）
- 三农-三农美食：开头食材出场有设计（如 A 把食材扔掉 B 捡回家）；大食材（半个牛、半个猪）；猎奇食材（娃娃鱼、鳄龟等）
- 三农-三农建造：唯美画面（夜晚雪景）；宏大建造（院子里的游泳池）；猎奇建造（深山手工搓 200 平房子、冰屋）；奇葩脑洞（倒立洗头机）

## 与数据表的对应关系

| 数据表 | 字段 | 对应方式 |
|---|---|---|
| 网络素材库 | 适配达人 | 文本格式 `达人类型：一级-二级；`，精确匹配（如 `达人类型：财经-泛财经`） |
| 历史数据库-头条 | 达人类型（select 枚举） | 二级类型 → 大类映射：财经系→`财经`；三农系→`三农`；剧情-常规剧情→`剧情`；剧情-剧情搞笑→`剧情搞笑`；生活系→`待确认`（历史库枚举值待补充） |
