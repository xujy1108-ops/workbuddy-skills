# 度小满-达人类型基础标准

> 来源：飞书文档 https://kwza968lz1u.feishu.cn/docx/Bt2wdpZmBo5Jk1xrfoxcAcoZnwe （revision 256）
> 本文件是风格匹配步骤的**唯一类型判定标准**。判定达人属于哪个类型时，必须严格依据下表的「范围限定」，只能从下表的一级/二级类型中选取，不得自创类型。
> 特别规则：**军事点评账号归入「财经-泛财经」**（标准原文："军事点评我们也算入泛财经范畴"）。

## 类型体系

| 一级达人类型 | 二级达人类型 | 范围限定 |
|---|---|---|
| 财经 | 泛财经 | 商业故事、个人财富、消费决策、搞钱思路、时政要闻、国内外热点等等所有与"金钱""财富""商业活动"相关的点评，输出观点；军事点评也算入泛财经范畴；方向可以垂直但不涉及投资；方向也可以很广，任何时事要闻、小道新闻都要表达看法 |
| 财经 | 高价值 | 主要讲投资：贵金属、二级市场投资（股票、债券、基金等）、房产、进出口等涉及金融投资；日常都是垂直赛道（要么一直讲贵金属、要么一直讲二级市场）；政策分析、投资心得分享、市场洞察、投资产品推荐等 |
| 财经 | 小微企业主 | 自己必须是老板/合伙人，有自己的公司和业务；日常分析自己公司产业看法、吐槽或点评创业中遇到的事情；每天创业 vlog 等 |
| 财经 | 常规 | 必须真实借贷故事分享，借贷用途不是小微企业主方向，可以是自己也可以是别人的；全程教他人怎么拒绝借钱/怎么解决，干货类分享，一定有解决方法，不是只提出问题 |
| 财经 | 鸡汤 | 情感鸡汤类分享，无故事讲述，从情感共鸣角度切入，大概描述借贷场景（人情债、借钱难等），用较多金句，讲述整体观点 |
| 三农 | 三农美食 | 围绕指定食材展开，一定有剧情演绎，核心是把食材有爽感地做饭；需要人物出镜说话，不能一直在厨房对着食材和锅拍摄；场景在农村（含少数民族场景如草原、窑洞）或城乡结合部，突出三农原生感；场景多元化（户外、院子、厨房） |
| 三农 | 三农建造 | 建造房子、家具、生活用具（泳池、猪圈等）手工内容，记录建造阶段或全程；需要人物出镜口播，不能只有旁白；每个视频都不能只提某个品牌家具或设备；场景可以在农村、野外，也可以在城市（如记录真实装修） |
| 剧情 | 常规剧情 | 剧情一般在 1 分钟以上；多人（非一人分饰多角）参与演出；多场景讲述剧情；剧情有人物关系、叙事结构（剧情梗概）、核心冲突；有完整的人物背景、故事起因、发展、高潮、结束/转折；叙事推进环环相扣 |
| 剧情 | 剧情搞笑 | 相比常规剧情，逻辑不严谨，时长可不到 1 分钟，主要体现无脑、耍丑、肢体动作搞笑；叙事推进可以不用环环相扣，会出现万万没想到的故事转折 |

## 账号举例（判定参考锚点）

- 财经-泛财经：商业小纸条、直言财经、达哥有点味（军事点评账号）
- 财经-高价值：小张小张吃饭用缸（吸钱哥）、财富觉醒社、许戈、大哲
- 财经-小微企业主：乡村大宁、豫游纪高公璞、包工头才哥
- 三农-三农美食：董姐夫美食、周甄甄、江小子
- 三农-三农建造：建造哥户外生活、文子大大、手工耿

## 爆款热区（创意方向参考）

- 财经-泛财经：蹭热点（与每个人相关的钱话题，如数字人民币、国补、消费贷补贴）；讲借钱遇到的坑及避坑；直接硬广讲产品核心卖点（网贷和银行借钱门槛区别等）
- 财经-高价值：常规叙事"不要借钱投资"；揭秘自己的经济情况；揭秘投资行业从业者经济情况；蹭热点
- 财经-小微企业主：讲述发家史；讲述自己遇到的经济周转情况；讲鸡汤说过去和现在的不容易
- 三农-三农美食：开头食材出场有设计（如 A 把食材扔掉 B 捡回家）；大食材（半个牛、半个猪）；猎奇食材（娃娃鱼、鳄龟等）
- 三农-三农建造：唯美画面（夜晚雪景）；宏大建造（院子里的游泳池）；猎奇建造（深山手工搓 200 平房子、冰屋）；奇葩脑洞（倒立洗头机）
