# 达人风格分析维度框架

本文档定义达人风格分析的三大维度及各子项的评分标准。评分均采用 0-100 分制，60 为及格线。

---

## 维度一：视觉/视频风格（Visual Style）

### 1.1 拍摄手法

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 运镜方式 | 推、拉、摇、移、跟、升降等 | 运镜丰富度、是否与内容匹配 |
| 景别使用 | 远景、全景、中景、近景、特写 | 景别切换频率、是否有固定偏好 |
| 机位角度 | 平视、俯拍、仰拍、侧拍 | 角度多样性、标志性角度 |
| 画面构图 | 对称、三分、引导线、中心构图 | 构图专业度、风格一致性 |

### 1.2 剪辑风格

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 转场频率 | 每分钟转场次数 | 节奏快/慢、是否影响观看体验 |
| 节奏感 | 镜头时长分布、节奏变化 | 节奏是否与内容匹配 |
| 特效使用 | 贴纸、动画、文字特效、转场特效 | 特效使用频率、风格统一性 |
| 声画配合 | 音乐与画面的配合度、卡点 | 声画同步度、音乐选择品味 |

### 1.3 视觉调性

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 色彩偏好 | 暖色系/冷色系/高饱和/低饱和 | 主色调、色彩倾向 |
| 滤镜风格 | 日系/欧美/胶片/自然/重度滤镜 | 滤镜统一性、品牌感 |
| 画面明暗 | 高调/低调/中间调、对比度 | 整体调性、视觉舒适度 |
| 字幕/文字 | 字体选择、排版风格、出现频率 | 文字设计专业度 |

### 1.4 画面节奏

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 信息密度 | 单位时间内传达的信息量 | 信息密度高低、是否适合目标受众 |
| 镜头时长 | 平均单镜头时长 | 长/短镜头偏好、是否有节奏变化 |
| 动静比例 | 动态画面与静态画面占比 | 动态感、视觉吸引力 |

---

## 维度二：内容/文案风格（Content Style）

### 2.1 文案调性

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 整体调性 | 专业/轻松/感性/幽默/理性/励志 | 主基调、一致性 |
| 情感倾向 | 正能量/中性/负能量/争议性 | 情感方向、受众感受 |
| 亲和力 | 与观众的距离感 | 距离近/远、是否说教 |

### 2.2 选题方向

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 内容主题 | 美妆/穿搭/美食/知识/娱乐/生活等 | 主题分布、专注度 |
| 选题角度 | 教程/测评/分享/故事/挑战/合集 | 角度多样性、创新性 |
| 热点追踪 | 是否紧跟热点话题 | 追热点能力、时效性 |
| 原创性 | 原创/搬运/二创比例 | 原创程度、内容独特性 |

### 2.3 叙事结构

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 开篇方式（Hook） | 提问/悬念/冲突/直入/数据冲击 | 开篇吸引力、3秒留存能力 |
| 正文结构 | 总分总/并列/递进/对比/时间线 | 逻辑清晰度、结构完整性 |
| 结尾模式 | 总结/互动/预告/号召/情感升华 | 结尾效果、互动引导 |
| 篇幅控制 | 文案字数、视频时长 | 篇幅是否合适、信息量把控 |

### 2.4 用词偏好

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 高频词汇 | 最常使用的词汇 Top 10 | 词汇特征、个人风格词汇 |
| 行业术语 | 专业术语使用频率与准确度 | 专业度、是否影响理解 |
| 口语化程度 | 书面语/口语比例 | 语言风格、亲切感 |
| 流行语使用 | 网络流行语/梗的使用 | 时髦度、是否生硬 |

## 维度三：运营/行为风格（Operational Style）

### 3.1 发布频率

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 日均发布量 | 平均每天发布内容数 | 更新频率 |
| 周均发布量 | 平均每周发布内容数 | 更新稳定性 |
| 发布间隔 | 两条内容之间的平均时间间隔 | 规律性、是否存在断更 |
| 更新趋势 | 近期发布频率的变化趋势 | 上升/下降/稳定 |

### 3.2 发布时间

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 活跃时段 | 最常发布的时间段分布 | 时段偏好（早/中/晚） |
| 时间规律性 | 发布时间的固定程度 | 规律性强/随机 |
| 最佳表现时段 | 互动数据最好的发布时段 | 数据驱动的时间策略 |

### 3.3 内容主题分布

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 主题占比 | 各类型内容在总量中的比例 | 内容结构是否均衡 |
| 主题表现对比 | 不同主题的互动数据差异 | 哪类内容最受欢迎 |
| 探索倾向 | 是否尝试新主题 | 创新意愿、试错频率 |

### 3.4 粉丝互动

| 子项 | 说明 | 评估要点 |
|------|------|----------|
| 回复评论习惯 | 是否回复评论、回复频率 | 互动意愿 |
| 互动引导方式 | 提问/投票/抽奖/挑战等 | 互动策略多样性 |
| 粉丝画像推测 | 根据内容推断粉丝群体特征 | 目标受众匹配度 |
| 社群运营 | 是否引导加群/关注其他平台 | 私域运营意识 |

---

## 评分标准

每个子项采用 0-100 分制：

| 分数区间 | 等级 | 说明 |
|----------|------|------|
| 85-100 | 优秀 | 特征鲜明、执行到位、效果突出 |
| 70-84 | 良好 | 有明显特征、执行较好 |
| 60-69 | 及格 | 有一定特征但不够突出 |
| 40-59 | 偏弱 | 特征不明显、执行一般 |
| 0-39 | 缺失 | 几乎无此特征或无法评估 |

维度总分 = 各子项加权平均（默认等权重，可根据平台特性调整）。

整体评分 = 三维度等权重平均（可根据需求调整权重配比）。
