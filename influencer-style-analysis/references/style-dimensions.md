# 达人风格分析维度框架

`influencer_profiler` 采用**动态多维度分析框架**，拒绝僵化枚举标签，以动态语言描述达人的多模态风格特征。

分析维度定义在 `scripts/agents/influencer_profiler.py` 的 `_SYSTEM_PROMPT` 中。

---

## 设计原则

1. **拒绝僵化标签**：禁止使用"亲切唠嗑"、"朴实接地气"等空泛枚举标签。必须使用**动态的语言描述**达人的语速节奏、情绪基调和视觉符号。
2. **克制推断边界**：基于视频样本分析，不过度推断或强行适配不相关品类。
3. **多模态视角**：不仅分析文本和语速，必须提取画面中的标志性视觉元素（穿搭、道具、机位、特效）。
4. **达人自身画像**：从 bio + 视频可视化信息推断达人自身的年龄、职业、外貌、讲话风格、资产层次，不预设任何职业分类。
5. **开放式标签**：style_tags 根据达人实际特征动态提取，不限于固定枚举。

---

## 分析维度

### 1. 基础定位（basic_positioning）

| 维度 | 分析要点 |
|------|----------|
| nickname | 达人昵称（来自 TikHub） |
| influencer_type | 达人类型，格式"一级-二级"（如"财经-泛财经"），依据《达人类型基础标准（终版）》判定，<=10字 |
| core_persona | 人设一句话总结，需突出差异化与记忆点（<=40字） |
| content_tracks | 核心内容赛道（2-3个，每个<=10字） |

分析依据：bio（达人简介）+ 视频内容

#### basic_positioning.influencer_demographic（达人自身画像）

| 维度 | 分析要点 | 示例 |
|------|----------|------|
| age_range | 年龄区间，从面部特征/言行推断（<=10字） | "30-35岁" |
| gender | 男/女/未知 | "男" |
| occupation | 职业身份（结合 bio 和视频口述，<=30字） | "前驻港部队退役，现自媒体" |
| appearance | 外貌与气质（<=25字） | "正气硬朗，身姿挺拔" |
| speech_style | 讲话风格与外显特质（<=25字） | "伶牙俐齿，逻辑清晰" |
| asset_level | 资产层次推断（高/中/一般）+ 理由（<=40字） | "bio 中身份暗示较高收入+视频穿搭简约" |
| verbal_pace | 语速：整体快/中/慢 + 约字数/分 + 关键变化点（<=45字），禁止"随情绪动态调整"这类无结论描述 | "整体偏慢（约150字/分），铺垫平稳，讲核心观点时略提速" |
| tone_and_emotion | 语气与情绪基调（<=20字） | "专业自信、略带犀利" |
| visual_symbols | 标志性视觉/听觉元素（<=50字） | "固定机位、深色背景、手持实物道具" |
| style_tags | **开放式**提取的风格标签（2-4个） | "硬核拆解"、"降维科普" |

分析依据：**视频观感 + bio 文本**。外貌/年龄/讲话风格从视频直接可见；职业/资产从 bio 身份标签 + 视频客观线索综合推断。

### 2. 受众洞察（audience_insight）

| 维度 | 分析要点 |
|------|----------|
| demographic | 人口统计学特征，如"25-45岁一二线男性"（<=20字） |
| psychological_needs | 受众心理诉求与痛点（<=50字） |

分析依据：视频内容主题 + 语气调性 + 选题方向

## 与旧版（8 类固定标签 + 7 维度）的差异

| 维度 | 旧版 | 新版 |
|------|------|------|
| 风格标签 | 8 类固定枚举，最多选 3 个 | 开放式提取，2-4 个，动态描述 |
| 语速 | 快/中/慢 枚举 | 必须给整体快/中/慢 + 字数 + 变化点 |
| 顶层维度数 | 7 维度（定位+受众+多模态+流量+商业+禁忌+脚本指南） | 2 维度（定位+受众） |
| 流量逻辑 | 独立维度（traffic_logic） | 已删除（不在风格分析产出） |
| 多模态风格 | 独立顶层维度 | 合并到 basic_positioning.influencer_demographic |
| 达人自身画像 | 无 | 新增 influencer_demographic 子对象（6 项达人画像字段） |
| 商业逻辑 | 独立维度（trust_builder/brand_fit/placement_style） | 已删除（不在风格分析产出） |
| 禁忌与风险 | 独立维度（taboos_and_risks） | 已删除 |
| 脚本生成指南 | 独立维度（ai_scripting_guide） | 已删除 |
| 视觉元素 | 未独立分析 | visual_symbols 专门提取 |
| 输出用途 | 风格摘要供参考 | 直接赋能下游 AI 脚本生成 |
